Google Sheet sync

Connect this CRM to a Google Sheet so everyone you share it with sees the same contacts. The sheet needs a tab named Contacts. Setup steps ▾

1. In Google Sheets, create a spreadsheet and add a tab named exactly Contacts.
2. Copy the Spreadsheet ID from its URL — the long id between /d/ and /edit.
3. In Google Cloud Console, enable the Google Sheets API and create an OAuth Client ID (Web application), adding this page's exact URL under Authorized JavaScript origins.
4. Paste the Client ID and Spreadsheet ID below, save, then sign in. Share the Sheet (Editor access) with anyone who should sync.
